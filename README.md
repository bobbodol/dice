# Игральные кости (D6)

Многоязычная утилита для симуляции бросков шестигранных игральных костей.  
Поддерживает броски нескольких костей, серии бросков, статистику выпадений и экспорт результатов.

## Особенности
- Бросок одной или нескольких костей (по умолчанию 1).
- Несколько бросков подряд (серия) с выводом результатов каждого броска.
- Подсчёт суммы выпавших значений для каждого броска.
- Накопление статистики по всем броскам (количество выпадений каждой грани).
- Воспроизводимость с помощью seed.
- Цветной вывод в терминале (где поддерживается).
- Экспорт результатов в форматы JSON и CSV.
- Поддержка аргументов командной строки для автоматизации и интеграции в скрипты.

## Установка и запуск
Для каждого языка требуются соответствующие инструменты и зависимости (указаны ниже).

### Запуск на разных языках

1. **Python**  
   Установка: `pip install colorama` (опционально).  
   Запуск: `python dice.py --roll 3 --count 5 --stats`

2. **JavaScript (Node.js)**  
   Установка: `npm install commander chalk`  
   Запуск: `node dice.js --roll 3 --count 5 --stats`

3. **Go**  
   Запуск: `go run dice.go --roll 3 --count 5 --stats`

4. **Rust**  
   Сборка: `cargo build --release`  
   Запуск: `cargo run -- --roll 3 --count 5 --stats`

5. **Java**  
   Сборка: `javac Dice.java`  
   Запуск: `java Dice --roll 3 --count 5 --stats`

6. **C# (.NET Core)**  
   Запуск: `dotnet run -- --roll 3 --count 5 --stats`

7. **C++ (Linux)**  
   Сборка: `g++ -std=c++11 -o dice dice.cpp`  
   Запуск: `./dice --roll 3 --count 5 --stats`

8. **Kotlin (JVM)**  
   Сборка: `kotlinc Dice.kt -include-runtime -d dice.jar`  
   Запуск: `java -jar dice.jar --roll 3 --count 5 --stats`

## Использование

Общие аргументы командной строки (везде, где поддерживается):

- `--roll <число>` – количество костей в одном броске (по умолчанию 1).
- `--count <число>` – количество бросков (по умолчанию 1).
- `--seed <число>` – seed для генератора случайных чисел (для воспроизводимости).
- `--stats` – вывести статистику выпадений по всем броскам.
- `--export-json <файл>` – экспортировать все результаты в JSON.
- `--export-csv <файл>` – экспортировать все результаты в CSV.
- `--help` – справка.
